Aplicación: Sistema de Gestión de Partidas de Dardos
Última actualización: 6 de noviembre de 2026

Resumen: la aplicación permite gestionar jugadores, partidas, resultados, estadísticas y preferencias de dardos. La información se guarda en el dispositivo. La aplicación no incorpora cuentas de usuario, publicidad ni funciones propias de analítica o envío de estos datos a servidores del desarrollador.

1. Responsable y contacto

Desarrollador: Mele Dev.
Para consultas sobre privacidad: meleroluis95@gmail.com.

2. Información utilizada

La aplicación procesa los nombres y colores de jugadores introducidos por el usuario, la configuración de las partidas, los resultados, el historial, las estadísticas y las preferencias de uso. Esta información se almacena localmente mediante SQLite y SharedPreferences.

3. Finalidad y comunicaciones

Estos datos se utilizan para las funciones de registro de jugadores, desarrollo y reanudación de partidas, clasificación, historial y estadísticas. La aplicación no requiere registro de cuentas ni utiliza los datos para publicidad o elaboración de perfiles. En esta versión no se han implementado funciones que transmitan esa información a servidores gestionados por el desarrollador.

4. Copias de seguridad y transferencia de dispositivo

Android puede realizar copias de seguridad o transferencias de los datos de la aplicación si el usuario tiene habilitadas las funciones correspondientes del sistema. Estas operaciones dependen de Android y de los servicios del dispositivo (por ejemplo, los servicios de copia de seguridad de Google), sujetos a sus propias condiciones y políticas de privacidad. No se trata de un servicio de sincronización gestionado por Mele Dev.

5. Conservación y eliminación

Los datos permanecen en el almacenamiento de la aplicación mientras el usuario los conserve. Para eliminar los datos locales en bloque, puede utilizar Ajustes del dispositivo → Aplicaciones → Sistema de Gestión de Partidas de Dardos → Almacenamiento → Borrar datos, o desinstalar la aplicación. Estas acciones pueden borrar de forma irreversible el historial y las estadísticas del dispositivo. Las copias de seguridad que ya existan se gestionan por separado desde el servicio correspondiente.

6. Seguridad

La aplicación utiliza el espacio de almacenamiento privado asignado por Android a cada aplicación. La seguridad adicional depende también de la configuración y protección del dispositivo, así como de los mecanismos de copia de seguridad que el usuario tenga activados.

7. Cambios en la política

Esta política podrá actualizarse si cambian las funciones o la forma de tratar los datos. La versión vigente estará disponible en esta misma página.
